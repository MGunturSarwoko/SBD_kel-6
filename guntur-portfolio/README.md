# Muhammad Guntur Sarwoko — Portfolio

A lightweight, dependency-free static portfolio site. It uses semantic HTML, custom CSS, and a small JavaScript layer for the English/Indonesian toggle, theme toggle, and editable photo placeholder.

## Run locally

From this folder, start any static file server, for example:

```bash
python -m http.server 8080
```

Then open <http://localhost:8080>.

## Validation

```bash
npm run check
```

To customize the social placeholders, replace the `href="#"` values in `index.html` with the LinkedIn and GitHub profile URLs.
