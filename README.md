# Portofolio Muhammad Faisal Ali Hafidz

Website portfolio satu halaman untuk menampilkan profil, kemampuan, pendidikan, dan proyek Muhammad Faisal Ali Hafidz.

## Jalankan secara lokal

1. Buka folder proyek.
2. Jalankan server lokal dengan perintah:

```bash
python -m http.server 8000
```

3. Buka browser di `http://localhost:8000`.

## Struktur file

- `index.html` — struktur halaman utama
- `style.css` — styling brutalist monokrom
- `script.js` — navigasi responsif dan modal detail proyek
- `assets/` — placeholder profil, aset proyek, dan file CV

## Ganti placeholder

Edit file berikut sesuai kebutuhan:

- `mailto:[Tambahkan email]` di `index.html`
- `[Tambahkan URL LinkedIn]`, `[Tambahkan URL GitHub]`, `[Tambahkan URL Instagram]`
- `assets/cv-placeholder.txt`
- `assets/profile-placeholder.svg`
- `assets/project-placeholder.svg`

Semua placeholder dibuat agar mudah diganti tanpa mengubah struktur utama website.
